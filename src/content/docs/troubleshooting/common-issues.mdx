# Common Issues

Solutions to frequently encountered problems in Barq Assets.

<Callout type="info">
**Under Construction:** This troubleshooting guide is being developed. Common issues and solutions will be added based on user feedback.
</Callout>

## Permission Errors

### "Access Denied" when viewing a page

**Problem**: You see an "Access Denied" or "Permission Required" message.

**Cause**: Your user account doesn't have the required permission for this feature.

**Solution**:
1. Contact your System Administrator
2. Request the specific permission needed (shown in the error message)
3. Once granted, refresh the page

---

### Cannot create or edit records

**Problem**: Create/Edit buttons are disabled or missing.

**Cause**: You have view-only permissions for this module.

**Solution**:
1. Check with your manager if you should have edit access
2. Request appropriate permissions from System Administrator

---

## Data Issues

### Records not appearing in lists

**Problem**: You created a record but can't find it in the list.

**Possible Causes**:
- Active filters hiding the record
- Permission restrictions
- Browser cache issues

**Solution**:
1. Clear all filters (click "Reset Filters")
2. Try refreshing the page (Cmd+R or Ctrl+R)
3. Check if record exists in search (Cmd+K)

---

### Import fails with validation errors

**Problem**: CSV import shows validation errors.

**Solution**:
1. Download the error report
2. Review the specific field errors
3. Correct data in your CSV file
4. Re-import the corrected file

**Common validation issues**:
- Missing required fields
- Invalid date formats (use YYYY-MM-DD)
- Reference IDs that don't exist
- Duplicate unique values

---

## Performance Issues

### Pages loading slowly

**Problem**: Pages take a long time to load.

**Possible Causes**:
- Large dataset being loaded
- Network connectivity issues
- Browser cache issues

**Solution**:
1. Try using filters to reduce dataset size
2. Clear browser cache and refresh
3. Check your network connection
4. Contact IT Support if issue persists
